## Penjelasan mengenai apa yang harus dilakukan

- **Prompt:** “Jelaskan fitur apa yang harus dibuat dan urutan yang harus dilakukan sampai dengan push GitHub.”
- **Dipakai:** Penjelasan umum mengenai project yang harus dibuat, fitur wajib, urutan pengerjaan, dan proses penggunaan GitHub.
- **Diubah:** Membuat gambaran awal implementasi aplikasi Personal Money Management dan menentukan tahapan pengerjaan.

## Pembuatan struktur HTML

- **Prompt:** “Buatkan struktur HTML untuk aplikasi Personal Money Management dengan form transaksi yang berisi tanggal, jenis transaksi, kategori, nominal, dan catatan opsional, serta bagian untuk menampilkan daftar transaksi.”
- **Dipakai:** Membantu menyusun struktur halaman utama aplikasi dan elemen form yang diperlukan untuk mencatat transaksi.
- **Diubah:** Menyesuaikan nama elemen HTML dan susunan halaman dengan rancangan aplikasi yang dibuat.

## Pembuatan tampilan CSS

- **Prompt:** “Buatkan CSS untuk aplikasi Personal Money Management dengan tampilan sederhana, warna pastel, form yang rapi, dan daftar transaksi yang mudah dibaca.”
- **Dipakai:** Membantu membuat tampilan aplikasi agar lebih terstruktur dan nyaman digunakan.
- **Diubah:** Menyesuaikan warna, jarak antarelemen, dan tata letak sesuai kebutuhan tampilan aplikasi.

## Implementasi JavaScript dan penyimpanan transaksi

- **Prompt:** “Buatkan JavaScript untuk menangani form transaksi, menampilkan daftar transaksi terbaru, menghapus transaksi dengan konfirmasi, dan menyimpan data menggunakan localStorage agar tidak hilang saat halaman dimuat ulang.”
- **Dipakai:** Membantu mengimplementasikan interaksi form, pengelolaan daftar transaksi, penghapusan data, dan penyimpanan lokal.
- **Diubah:** Menyesuaikan fungsi JavaScript dengan ID elemen HTML dan struktur data transaksi yang digunakan dalam project.

## Validasi dan pengujian awal

- **Prompt:** “Bantu periksa validasi form transaksi agar kolom wajib diisi dan nominal harus lebih dari nol. Tampilkan pesan kesalahan pada halaman.”
- **Dipakai:** Membantu memeriksa kebutuhan validasi input agar data transaksi yang dimasukkan sesuai ketentuan.
- **Diubah:** Menyesuaikan validasi dan pesan kesalahan dengan elemen form yang tersedia, kemudian menguji kembali perilaku aplikasi.

## Penggunaan Git dan GitHub

- **Prompt:** “Jelaskan langkah-langkah menggunakan Git di VS Code untuk menambahkan file, membuat commit, dan mengirim project ke repository GitHub.”
- **Dipakai:** Memahami tahapan menyimpan perubahan project menggunakan Git dan mengunggahnya ke repository GitHub.
- **Diubah:** Menjalankan perintah Git melalui terminal VS Code sesuai kondisi repository dan perubahan file yang dilakukan.
