## Deskripsi Aplikasi

Ruang Anggaran adalah aplikasi web sederhana untuk membantu mengelola keuangan rumah tangga. Pengguna dapat mencatat pemasukan dan pengeluaran, memantau saldo, serta mengatur anggaran berdasarkan kategori kebutuhan keluarga.

## Fitur Aplikasi

- Mencatat transaksi pemasukan dan pengeluaran.
- Menampilkan ringkasan pemasukan, pengeluaran, dan saldo.
- Menampilkan daftar transaksi.
- Menyimpan data menggunakan Local Storage pada browser.
- Mengatur anggaran berdasarkan kategori kebutuhan rumah tangga, seperti Belanja Dapur, Transportasi, dan Pendidikan.

## Teknologi yang Digunakan

- HTML untuk struktur halaman.
- CSS untuk tampilan dan tata letak.
- JavaScript untuk logika aplikasi dan pengolahan transaksi.
- Local Storage untuk penyimpanan data di browser.

## Cara Menjalankan Aplikasi

1. Unduh atau clone repository ini.
2. Buka folder project di Visual Studio Code.
3. Buka file `index.html` menggunakan browser, atau jalankan dengan ekstensi Live Server.
4. Gunakan formulir yang tersedia untuk mencatat transaksi.
